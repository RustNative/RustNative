## Indicators added (L7)

- **L7.1 URL-context safety** (F1): every URL-valued attribute (`href`, `action`, `src`, `formaction`, `poster`) is passed through one `SafeUrl` type that allows `http`, `https`, `mailto`, `tel`, and relative URLs, and refuses `javascript:`, `data:` (except images), and `vbscript:`, after the WHATWG URL parser's normalisation (leading whitespace and control characters, mixed case, entity forms). It is a type, so a raw `&str` cannot reach an `href` (E5). The test corpus is the OWASP XSS filter-evasion URL list, run through the server and through the client realizer in a browser.
- **L7.2 CSS value grammar** (F2, L1): every value emitted into CSS goes through one serializer per CSS type (`<family-name>` as a CSS string with `\` escapes, colours, lengths), never `format!` of raw text. The test feeds `}`, `;`, `/*`, `\`, `</style>`, and newlines through every style property and asserts the parsed stylesheet's rule count is unchanged.
- **L7.3 Name validation** (F3): `Element::attr`/`set` reject names outside the HTML attribute-name grammar and refuse `on*` unless explicitly unsafe-marked.
- **L7.4 Generative translator equivalence** (F4): a program generator over the client subset (arith on every width, string methods on random Unicode, including astral and combining characters, collections, control flow, panics), run in Rust and in Node. Any difference in result or failure is a failure, 10 000 programs per CI run, with Node required.
