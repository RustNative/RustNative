| L3-F17 | **P1** | **A transient read error destroys saved state.** `StateCache::read` maps `store.load(key)` errors to absence (`.ok().flatten()`) and caches `None`; the component sees its default, and its next `set` overwrites the real file at the next flush. | L3-F18 | P2 | **Schema change silently resets state**: a stored value that no longer deserializes reads as the default (tested as intended), and the next write replaces it — no version, no migration hook, no diagnostic. A corrupt state file (checksum mismatch) also reads as absent with no report. | `persisted.rs` `get`/`set`; `services/file_state.rs` `decode` |
| L3-F19 | **P1 (security, Linux)** | **The inspector's token is written to a shared temp directory**: `endpoint_directory()` = `temp_dir()/rustnative-inspect/<pid>.json` holding the address and the token. On Linux `/tmp` is shared by all users, the file gets the default umask (world-readable), and the directory is created without ownership/permission checks (another user can pre-create or symlink it). Whoever reads the token can read every string in the UI and edit component state (`edit_component`) or drive it. | `inspect/server.rs` `publish`, `endpoint_directory`; `component/tree/inspection.rs` `edit_component` |

## Indicators added (part 2)

- **L3.8.7 Load errors never become absence** (F17): a store whose `load` fails once must not lead the next `set`+`flush` to overwrite the file — test with a store that fails one load.
- **L3.8.8 Format evolution** (F18): every persisted value travels in a versioned envelope with an upgrade function; a value that fails to deserialize is quarantined (kept and reported), never overwritten.
- **L3.10.7 Inspector exposure** (F19, F20): endpoint files in a per-user `0700` directory (`XDG_RUNTIME_DIR` on Linux), files `0600`; release builds start the inspector only if the application opted in at compile time; request lines bounded (1 MiB) and connections capped; a test as a second Unix user cannot read the token.
- **L3.4.8 Task failure delivery** (F21): for each spawn flavour (`spawn`, `spawn_local`, `spawn_supervised` × 3 policies, `collect`, `offload`, `deferred`) a panic reaches the component as a failure or escalates to the panic policy — and `task_count()` returns to 0.
- **L3.4.9 Cooperative budget** (F22): a local task that always wakes itself cannot keep `pump_tasks` running longer than the render budget.
- **L3.4.10 Blocking-work isolation** (F23): while two 1 s `deferred` computations run, a 10 ms timer fires within 20 ms.
- **L3.4.11 Bounded result queue** (F24) and **no callback under a lock** (F25: a debug lock-depth assertion at every waker/callback invocation).
- **L3.3.10 Layout input bounds** (F26): placements beyond `children + rows` are clamped or rejected; property test with arbitrary `usize` placements under a memory cap.
- **L3.3.11 Measurement count** (F27): a counting measurer bounds measure calls per layout at ≤ 4·n for generated trees of depth ≤ 20.
