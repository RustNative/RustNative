## Indicators added (part 1)

- **L3.1.9 Diff completeness** (catches F1): a generated test that, for every field of every `Node` payload (enumerated from `TreeNode`), changing only that field produces at least one `Update` op — and a compile-time guard: `node_changed` compares `TreeNode` via a destructuring `let TreeNode { id: _, kind, … } = …` so adding a field without deciding its diff behaviour fails to compile (E5).
- **L3.2.7 Panic containment matrix** (F2, F3): for each user-code entry point (constructor, `mounted`, `render`/`view`, `update`, `message`, `set_props`, `props_changed`, effect body, effect cleanup, `unmounted`, `Drop`) × (inside a boundary, outside a boundary with `ReportAndContinue`): after the panic, the tree still renders, every removed component got `unmounted()` and its effect cleanups ran exactly once. 22 cases, each a test.
- **L3.8.5 Flush covers lifecycle reactions** (F4): a component that writes `Persisted` in `update(Event::Lifecycle(Terminating))` finds the value in the store when `lifecycle()` returns.
- **L3.10.6 Crash reports redact** (F5): text-input values, secure fields, and any node marked private are absent from the stored tree; a test asserts a marker string typed into a `TextInput` never appears in a report file. Reports from contained panics are marked non-fatal and the directory is bounded (F6).
- **L3.1.10 Syntax equivalence on boundary values** (F7): the equivalence suite includes out-of-range and edge values for every attribute, not only typical ones.
- **L3.1.11 Supported depth** (F8): a documented maximum tree depth per backend thread stack, and a test at that depth on a 1 MiB stack through the whole pipeline (render → snapshot → diff → resolve → layout); beyond it, a `RenderError::TooDeep`, never an abort.
- **L3.8.6 Stable persistence keys** (F10): a persisted key for a given component path is byte-identical across a rename of the root type's module (test: two `type_name`-different but path-equal roots read the same state), or keys come from an explicit stable id.
