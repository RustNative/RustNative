# L4 — reference realizations: `rustnative-headless`, `rustnative-conformance`, `rustnative-web-testing` (deep read, iteration 1)

L4 is the layer that every other layer is *measured with*. A defect here is not a product bug; it is an **instrument defect**: it makes a real product bug invisible. Severity is graded by how much it hides.

Read in full: headless `src/*` (all files); conformance `src/{lib,suites,host,reference}.rs` and tests `doc_claims`, `doc_parity`, `guarantees`, `wire`, `compile_fail`, `layout_conformance`, `style_equivalence`, `syntax_equivalence`, `cancellation_property`; `ui/*`, `style_ui/*` cases; `rustnative-web-testing/src/lib.rs`.

## Indicators added (L4)

- **L4.1 Realization fidelity** (F1): the reference realization applies **only** `Patch` ops to its object tree. A parallel "rebuild from snapshot" tree is compared after each settle, and any difference fails with the node and field (this one oracle makes every L3-F1-class bug fail every test).
- **L4.2 Honest kill** (F2): `kill_and_restore` leaks the app (`std::mem::forget` or a child process with `SIGKILL`/`TerminateProcess`); a separate `terminate_and_relaunch` delivers `Terminating` and then forgets.
- **L4.3 No silent no-ops in drivers** (F3, F4, F6, F7): every driver method returns `Result` and errors when the action had no effect or no target. `settle` errors after its bound. Golden creation needs an explicit opt-in.
- **L4.4 Driver completeness** (F8): the `Driver` trait covers every input category in the backend checklist (key, shortcut, focus/Tab, hover, drag, IME, clipboard, lifecycle, resize/scale, a11y action, window command). A table test maps each checklist row to at least one shared suite.
- **L4.5 Boundary-value equivalence** (F9): for every attribute and property, cases include min, max, below-min, above-max, zero, negative, `nan`/`inf` (where the type allows), empty, and very long values.
- **L4.6 Cross-realization equivalence** (F10): the style cases are realized through the Web backend's CSS in a browser and through headless; computed geometry and colour must match.
- **L4.7 Mandatory instruments in CI** (F13): CI sets `RUSTNATIVE_BROWSER_REQUIRED=1` (and the equivalent for every other skip-if-absent harness: Node, Xvfb, emulator). A job whose required instrument is missing fails.
