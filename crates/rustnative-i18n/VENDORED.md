# Vendored data

`src/plural.rs` transcribes the cardinal plural rules of the Unicode Common
Locale Data Repository (CLDR 45, `common/supplemental/plurals.xml`) for the
shipped locales (en, de, fr, ar, he, pl, ru, ja, zh, ko), restricted to
whole numbers. The data is © Unicode, Inc., used under the Unicode License
v3 (https://www.unicode.org/license.txt); its sample numbers are the
module's tests.
